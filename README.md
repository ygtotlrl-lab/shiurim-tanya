# שיעורים — סריקות השיעורים

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו, והאפליקציה קוראת ממנו.

- `p/` — עמודי ליקוטי אמרים (תניא, קה״ת תשט״ז), תמונה לכל עמוד: עמודי הספר, לוח התיקון והערות ותיקונים.

שיעור חדש נכנס לכאן בתיקייה משלו, כל עוד האתר נשאר מתחת ל-1GB.
